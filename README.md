# FileKit SEO site

1. Replace `https://filekitonline.com` and `hello@yourdomain.com` in every file (use your editor's find and replace across the folder).
2. Upload this folder to Vercel (drag and drop or `vercel deploy`) and connect your domain.
3. In Google Search Console add your domain and submit `/sitemap.xml`.
4. Add a 1200x630 image and an `og:image` tag if you want rich link previews.

## Backlinks (links from other sites)
They cannot be generated by code. Earn them with: genuinely useful guides others cite, posting your tools in relevant communities (Reddit, Quora answers, Facebook groups, LinkedIn), listing on legitimate tool directories, and asking sites that write about productivity tools to mention you. Avoid bought links and link farms, because they can get the site penalised.
