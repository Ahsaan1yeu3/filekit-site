About FileKit

Simple file tools that respect your privacy.

FileKit is a free set of everyday file tools: convert Word to PDF, PDF to Word, Excel to Word or PDF, resize images, remove marks from images, change photo backgrounds, and view documents without installing anything.

Why we built it

Most online converters ask you to upload your files to a server. Contracts, CVs, ID photos and invoices are personal, so FileKit does the work inside your own browser instead. Your files are never sent to us.

What you can expect

  • No sign-up and no software to install.
  • Clear tools with honest limits explained on each page.
  • Guides that explain how to get the best result from each tool.
